# NOVA FORGE

Mistral AI tasarım analiz dosyasındaki sıcak gün batımı paleti, editoryal başlıklar, düz kartlar ve alt bölümdeki sunset stripe yaklaşımından esinlenen özgün, responsive teknoloji sitesi.

## Çalıştırma
`index.html` dosyasını tarayıcıda aç. Harici kütüphane veya derleme adımı gerektirmez. Google Fonts bağlantısı için internet gerekir; bağlantı yoksa sistem fontları kullanılır.

## Dosyalar
- `index.html`: sayfa içeriği
- `style.css`: responsive tasarım
- `script.js`: mobil menü ve e-posta taslaklı iletişim formu

İletişim formu bir sunucuya veri göndermez. Formu doldurunca kullanıcının e-posta uygulamasında taslak açar.
